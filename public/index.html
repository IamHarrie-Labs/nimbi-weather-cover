How a settlement happens
01

Read

The agent asks six independent oracles the same question about the same place, right now.

02

Consensus

Whichever oracles land close together form the majority. Anyone far outside that group gets named and left out, not quietly averaged in.

03

Settle

If a real majority agreed and the threshold was crossed, the contract pays out immediately. If not, it holds the money and records why.
